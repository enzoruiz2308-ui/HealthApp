# HealthApp

Health-care home screen built with Android **ConstraintLayout**.
Activity 1 - pair project.

## Screen

- **Header:** profile photo and notification bell
- **Welcome card:** greeting, doctor photo and Urgent Care button
- **Our Services:** Consultation, Medicines, Ambulance
- **Appointment:** card with date, time, doctor name and specialty
- **Bottom navigation:** home, documents, +, chat, profile

## How to run

1. Clone: `git clone https://github.com/enzoruiz2308-ui/HealthApp.git`
2. Switch branch: `git checkout final`
3. Open the folder in Android Studio and click Sync Now
4. Press Run

## APK

Build > Build APK(s). The file is generated at `app/build/outputs/apk/debug/app-debug.apk`
